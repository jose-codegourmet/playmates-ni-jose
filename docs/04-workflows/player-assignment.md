# Player Assignment Workflow

## Fast assignment is important

Player selection can otherwise become another repetitive task.

## Session roster

When a session is created, select the people who attended.

Game player pickers should default to this roster rather than the entire player database.

## Game assignment UI

Show two team zones:

```text
Team 1
[ José ] [ Carlo ]

vs

Team 2
[ Mika ] [ Marco ]
```

Actions:
- search player
- drag player between teams
- clear team
- swap teams
- copy previous game's matchup
- rematch previous game
- rotate one player

## Player not in database

Provide inline:
`+ Add new player`

Only require:
- display name

Everything else is optional.

## Facebook identity

Facebook tagging should not be required.

Optional player fields:
- Facebook display name
- Facebook profile URL

Generated Facebook copy uses plain player names by default.
