# Public Site

## Home

The public home page should communicate:
- Playmates ni José
- latest badminton sessions
- recent games
- easy player access

Avoid turning it into a marketing landing page unless desired later.

## Sessions index

Filters:
- date
- player
- venue

Cards:
- date
- venue
- number of games
- participating players
- thumbnail if available later

## Session detail

Show:
- date
- venue
- players
- game list

Each game card:
- Game number
- matchup
- video count
- YouTube play/open actions
- Drive access
- game detail link

## Game page

Show:
- matchup
- date/venue
- ordered recordings
- embedded YouTube where possible
- Drive links
- navigation previous/next game

When multiple parts exist, make the sequence obvious.

## Player page

Show:
- name
- recent sessions
- recent games
- teammates/opponents later
- stats later

## Venue page

Show:
- venue name
- session history

## Privacy

Only show records explicitly public/published.
