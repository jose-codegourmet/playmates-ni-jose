# Glossary

## Session
One badminton outing or recording date. A session contains one or more games.

Example: `September 9, 2026 — Marigondon Badminton Session`.

## Game
One badminton match inside a session.

Example: `Game 3`.

## Recording
One physical video file captured by one phone/camera.

A single game can contain multiple recordings.

## Side A / Side B
Logical camera viewpoints. They do **not** mean Team A or Team B.

A recording's side is independent from which players are on each team.

## Part
Sequence number when one side has multiple video files due to interruption.

Example:
- Game 2 / Side B / Part 1
- Game 2 / Side B / Part 2

## Team
A set of players competing together in a game. Usually doubles, but the data model should not unnecessarily prevent singles.

## Player
A person who participates in games.

## Venue
A badminton location/facility.

## Court
Optional subdivision of a venue such as Court 1, Court 2, Court A.

## Publish
The broader process of uploading recordings to external services and making the game/session visible in the public archive.

## Provider asset
A remote version of a recording, such as:
- Google Drive file
- YouTube video

## Upload job
Tracked work that uploads one recording to one provider.

## Facebook post draft
Generated text for manually publishing a game to the Playmates ni José Facebook Group.
